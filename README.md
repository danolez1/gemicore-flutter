# Gemicore for Flutter

Purchases for Flutter apps on the Gemicore API: App Store and Google Play subscriptions and one-time products, offerings and paywalls, the Customer Center, placements and experiments, and card, Apple Pay and Google Pay payments, all behind one publishable API key.

| Package | What it is |
|---|---|
| [`gemicore_flutter`](gemicore_flutter) | The SDK: purchases, restore, entitlements, paywall widget, Customer Center |
| [`gemicore_flutter_stripe`](gemicore_flutter_stripe) | Optional add-on that shows the Apple Pay and Google Pay sheet through Stripe |

The setup guide, the REST reference and the dashboard steps are in the [in-app purchases guide](https://gemicore.com/docs/guide/in-app-purchases).

This repository is a release mirror of the SDK folder of the Gemicore monorepo, so each commit is one release. Please report problems in the issue tracker.
